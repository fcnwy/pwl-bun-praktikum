Apa perbedaan Bun.js dan Node.js menurut pemahaman Anda?
-Menurut pemahaman saya sejauh ini, Bun.js lebih cepat dan footprintnya ringan dibanding Node.js, bisa dikatakan bahwa Bun.js lebih modern dari pada Node.js. Namun, Node.js cocok untuk digunakan di industri sebagai runtime konvensional. Node.js disarankan untuk penggunaan skala besar, sedangkan Bun.js dapat digunakan untuk pengembangan yang cepat atau modern stack.

Mengapa Git penting dalam pengembangan perangkat lunak?
-Git penting dalam pengembangan software untuk melacak perubahan kode, menyimpan histori pengembangan, dan juga dapat digunakan dalam kolaborasi tim. Hal ini memungkinkan perubahan dalam kode tercatat.
